# NayePankh Foundation Website

A modern and responsive website developed for NayePankh Foundation as part of a Front-End Development internship task.

## Live Demo

https://nayepankh-foundation-one.vercel.app

## GitHub Repository

https://github.com/saurabhbisht31/nayepankh-foundation

## Features

* Responsive modern UI
* Smooth scrolling navigation
* Dark Mode toggle
* Hero section
* About Us section
* Programs section
* Volunteer registration form
* Contact section
* Footer with social links
* Scroll-based animations

## Technologies Used

* React.js
* Vite
* JavaScript (ES6+)
* HTML5
* CSS3
